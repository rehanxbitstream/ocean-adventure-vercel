# Ocean Adventure — Gameplay Test Checklist

Use this checklist after opening `index.html` with VS Code Live Server.

## Desktop
- [ ] Start button begins a new run and hides the menu.
- [ ] Arrow keys and W/A/S/D move the diver; Space swims upward.
- [ ] P or Escape pauses once; Resume continues without a sudden time jump.
- [ ] Holding P does not rapidly toggle pause/resume.
- [ ] Sound button toggles sound on and off.
- [ ] Pearls, golden pearls, and treasure chests award the displayed points.
- [ ] Oxygen tanks restore oxygen; oxygen drains over time.
- [ ] Mine, shark, and jellyfish collisions reduce lives only once per invulnerability window.
- [ ] Shield pickup protects against one hazard collision and expires after its timer.
- [ ] Level increases at score thresholds and difficulty increases.
- [ ] Game over shows final score, best score, level, distance, and oxygen used.
- [ ] Replay resets the run but keeps the best score.

## Mobile / tablet
- [ ] Portrait and landscape layouts do not create horizontal page scrolling.
- [ ] HUD remains readable and does not cover the whole play area.
- [ ] Each touch direction works while held and stops on release.
- [ ] Touch controls do not activate the Start, Pause, or Sound buttons accidentally.
- [ ] Rotating the device does not leave a movement direction stuck.

## Record issues
For each issue, note the device/browser, screen orientation, steps to reproduce, and what you expected versus what happened.
